## Estruturas Homogêneas

Armazenam elementos do **mesmo tipo de dado**, garantindo alocação de memória uniforme.

---

### Array (Vetor Estático)

Sequência contígua de elementos do mesmo tipo na memória.

```
  int numeros[4] = {5, 3, 1, 9};

  endereço: [1000] [1004] [1008] [1012]
             +-----+-----+-----+-----+
  valores:   |  5  |  3  |  1  |  9  |
             +-----+-----+-----+-----+
  posição:     [0]   [1]   [2]   [3]

  acesso: numeros[2] → 1
          (vai direto ao endereço 1000 + 2×4 = 1008)
```

```c
#include <stdio.h>

int main() {
    int numeros[5] = {1, 2, 3, 4, 5};   // array de inteiros
    char letras[3] = {'A', 'B', 'C'};   // array de caracteres

    printf("Primeiro numero: %d\n", numeros[0]);   // 1
    printf("Primeira letra: %c\n",  letras[0]);    // A

    return 0;
}
```

---

### Matriz (Array Bidimensional)

Array de arrays — organizado em linhas e colunas.

```
  int matriz[2][4] = {{5, 3, 1, 9},
                      {2, 4, 7, 6}};

           col 0  col 1  col 2  col 3
  linha 0 | 5   |  3   |  1   |  9   |
          +-----+------+------+------+
  linha 1 | 2   |  4   |  7   |  6   |

  acesso: matriz[0][1] → 3   (linha 0, coluna 1)
          matriz[1][2] → 7   (linha 1, coluna 2)
```

```c
#include <stdio.h>

int main() {
    int matriz[2][3] = {{1, 2, 3},
                        {4, 5, 6}};

    // elemento da linha 0, coluna 1
    printf("matriz[0][1] = %d\n", matriz[0][1]);   // 2

    // percorrendo toda a matriz
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matriz[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

### Vetor Dinâmico (malloc)

Alocado em tempo de execução no **heap** — tamanho definido durante o programa.

```
  ARRAY ESTÁTICO                    VETOR DINÂMICO
  tamanho fixo em compilação        tamanho definido em execução

  stack (memória automática)        heap (memória manual)
  +-----+-----+-----+-----+         endereços espalhados:
  |  0  |  2  |  4  |  6  |
  +-----+-----+-----+-----+        [0x741598] → 0
    [0]   [1]   [2]   [3]          [0x258741] → 2
                                   [0x582791] → 4
  liberado automaticamente          [0x357951] → 6

                                   precisa de free() manual!
```

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int tamanho = 5;
    int *vetor = (int*) malloc(tamanho * sizeof(int));

    if (vetor == NULL) {
        printf("Erro de alocacao de memoria!\n");
        return 1;
    }

    for (int i = 0; i < tamanho; i++) {
        vetor[i] = i * 2;
        printf("%d ", vetor[i]);   // 0 2 4 6 8
    }

    free(vetor);   // libera a memória — obrigatório!
    return 0;
}
```

### Comparando os três

```
             Array          Matriz         Vetor Dinâmico
  ────────── ────────────── ────────────── ──────────────────
  Dimensões  1D             2D (ou mais)   1D (ou mais)
  Tamanho    fixo           fixo           definido em execução
  Memória    stack          stack          heap
  Liberar?   não            não            sim (free)
  Acesso     v[i]           m[i][j]        v[i]
```

## Estruturas Heterogêneas — Struct

Agrupam variáveis de **tipos diferentes** sob um único nome. Equivale a criar um novo tipo de dado.

```
  struct Funcionario
  ┌──────────────────────────────┐
  │ idade   → int    (4 bytes)   │  endereço 100
  │ nome    → char[40](40 bytes) │  endereço 104
  │ salario → float  (4 bytes)   │  endereço 144
  └──────────────────────────────┘

  acesso: empregado.idade
          empregado.nome
          empregado.salario
          ( operador ponto . )
```

---

### Declarando Structs

```c
// jeito 1 — declara a struct e depois as variáveis separado
struct Funcionario {
    int   idade;
    char  nome[40];
    float salario;
};
struct Funcionario empregado;
struct Funcionario chefe;

// jeito 2 — declara a struct e as variáveis juntas
struct Funcionario {
    int   idade;
    char  nome[40];
    float salario;
} empregado, chefe, secretaria;
```

---

### Usando typedef

O `typedef` evita ter que escrever `struct` toda vez.

```
  SEM typedef                       COM typedef
  ───────────────────────           ───────────────────────
  struct Funcionario emp;           Func emp;
  struct Funcionario chefe;         Func chefe;
  (mais verboso)                    (mais limpo)
```

```c
// jeito 1 com typedef — separado
struct Funcionario {
    int   idade;
    char  nome[40];
    float salario;
};
typedef struct Funcionario Func;
Func secretaria;

// jeito 2 com typedef — junto
typedef struct Funcionario {
    int   idade;
    char  nome[40];
    float salario;
} Func;
Func secretaria;

// jeito 3 com typedef — sem nome da struct (mais comum)
typedef struct {
    int   idade;
    char  nome[40];
    float salario;
} Func;
Func secretaria;
Func funcionarios[10];   // vetor de structs
```

---

### Inicializando Structs

```c
typedef struct {
    int   idade;
    char  nome[40];
    float salario;
} Func;

// jeito 1 — inicialização direta (na ordem dos campos)
Func secretaria = {40, "Maria", 2500.00};
Func chefe      = {45, "Jose",  12500.00};

// jeito 2 — campo a campo
Func chefe;
chefe.idade   = 45;
strcpy(chefe.nome, "Jose");   // strings precisam de strcpy!
chefe.salario = 12500.00;

// jeito 3 — lendo do usuário
Func chefe;
printf("Idade: ");    scanf("%d",  &chefe.idade);
printf("Nome: ");     scanf("%s",   chefe.nome);
printf("Salario: ");  scanf("%f",  &chefe.salario);
```

> **Atenção com strings:** use `strcpy(dest, src)` para copiar — nunca `chefe.nome = "Jose"` diretamente.

## Estruturas Aninhadas

Uma struct pode ter como campo outra struct.

```
  Venda
  ┌─────────────────────────────────────────┐
  │ pecas    → int                          │
  │ preco    → float                        │
  │ diaVenda → Data ┌──────────────────┐   │
  │                 │ dia  → int       │   │
  │                 │ mes  → char[10]  │   │
  │                 │ ano  → int       │   │
  │                 └──────────────────┘   │
  └─────────────────────────────────────────┘

  acesso ao campo aninhado:
  A.diaVenda.dia   → operador ponto duas vezes
  A.diaVenda.mes
  A.diaVenda.ano
```

```c
typedef struct {
    int  dia;
    char mes[10];
    int  ano;
} Data;

typedef struct {
    int   pecas;
    float preco;
    Data  diaVenda;   // struct dentro de struct
} Venda;

int main() {
    Venda A = {20, 115.0, {8, "Dezembro", 2020}};

    printf("Pecas: %d\n",   A.pecas);
    printf("Preco: %.2f\n", A.preco);
    printf("Data: %d de %s de %d\n",
           A.diaVenda.dia,
           A.diaVenda.mes,
           A.diaVenda.ano);
    return 0;
}
```

## Cuidado — Struct não pode conter a si mesma

```
  ERRADO                            CORRETO
  ──────────────────────            ──────────────────────
  struct Aluno {                    struct Aluno {
    int  matricula;                   int  matricula;
    char nome[40];                    char nome[40];
    int  idade;                       int  idade;
    struct Aluno aluno1; // ERRO!     struct Aluno *ptr;  // OK
  };                                };

  por quê?                          ponteiro tem tamanho fixo
  o compilador não consegue         (8 bytes) — o compilador
  calcular o tamanho da struct      já conhece esse tamanho
  (seria infinita)
```

## Vetor de Structs

Combina array com struct — armazena vários registros do mesmo tipo.

```
  Func chefe[3];

  chefe[0]               chefe[1]               chefe[2]
  ┌────────────────┐     ┌────────────────┐     ┌────────────────┐
  │ idade: 45      │     │ idade: 30      │     │ idade: 25      │
  │ nome: "Jose"   │     │ nome: "Ana"    │     │ nome: "Bia"    │
  │ salario: 12500 │     │ salario: 5000  │     │ salario: 3500  │
  └────────────────┘     └────────────────┘     └────────────────┘
     [0]                    [1]                    [2]

  acesso: chefe[1].nome    → "Ana"
          chefe[0].salario → 12500
```

```c
typedef struct {
    int   idade;
    char  nome[40];
    float salario;
} Func;

int main() {
    Func chefe[3];

    for (int i = 0; i < 3; i++) {
        printf("Nome: ");    scanf("%s",  chefe[i].nome);
        printf("Idade: ");   scanf("%d", &chefe[i].idade);
        printf("Salario: "); scanf("%f", &chefe[i].salario);
    }

    for (int i = 0; i < 3; i++) {
        printf("%s — %d anos — R$ %.2f\n",
               chefe[i].nome,
               chefe[i].idade,
               chefe[i].salario);
    }
    return 0;
}
```

## Resumo — Homogêneas vs Heterogêneas

```
  HOMOGÊNEAS                        HETEROGÊNEAS
  ──────────────────────────        ──────────────────────────
  mesmo tipo em todos campos        tipos diferentes misturados
  array, matriz, vetor dinâmico     struct / registro
  acesso por índice: v[i]           acesso por nome: s.campo
  memória uniforme                  memória por campo
  tamanho = n × sizeof(tipo)        tamanho = soma dos campos
```
