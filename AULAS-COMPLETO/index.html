Fundamentos · Ponteiros

Ponteiros em C++

A base de listas, pilhas, filas e árvores. Dominar as 3 formas de passar parâmetros — valor, referência e ponteiro duplo — é essencial para a AV1.

Por que 3 formas? Cada uma tem um trade-off. O professor usa todas as três nos arquivos .cpp.

As 3 formas de passar parâmetros

① Por Valor (Retorno)
Recebe cópia. Main precisa capturar: head = func(head, val)
Arquivo: Listas.cpp
② Por Referência (No*&)
Modifica head diretamente. Sem retorno: func(head, val)
Arquivo: Listas2.cpp
③ Ponteiro Duplo (No**) — estilo C
Passa endereço do ponteiro. Usado nos Exercícios AV1: void inserirFinal(No **lista, int valor). Equivale ao No*& mas funciona em C também.

Código comparativo

C++
No* inserirInicio(No* head, int valor) {
    No* novoNo = new No;     // aloca no heap
    novoNo->dado = valor;
    novoNo->prox = head;      // novo → antigo início
    return novoNo;             // retorna o novo head
}
// Uso — PRECISA capturar retorno:
head = inserirInicio(head, 10);
C++
void inserirInicio(No*& head, int valor) {
    No* novoNo = new No(valor); // com construtor
    novoNo->prox = head;
    head = novoNo; // modifica head original diretamente
}
// Uso — sem capturar retorno:
inserirInicio(head, 10);
C / C++
void inserirFinal(No** lista, int valor) {
    No* novo = new No;
    novo->dado = valor;
    novo->prox = nullptr;
    if (*lista == nullptr) { *lista = novo; return; }
    No* atual = *lista;
    while (atual->prox) atual = atual->prox;
    atual->prox = novo;
}
// Uso — passa endereço do ponteiro:
inserirFinal(&head, 10);
No** vs No*&: Fazem a mesma coisa — permitem modificar head de dentro da função. A diferença é só sintaxe. No*& é C++ puro; No** funciona em C e C++. A AV1 usa No** nos enunciados.

Armadilhas

❌ Esquecer retorno
Se retorna No*, precisa head = func(head, val). Sem o head =, a lista não muda.
❌ Acessar ponteiro null
Sempre cheque if (!head) antes de head→dado. Acessar null é undefined behavior.
❌ Esquecer o delete
Todo new precisa de delete. Remover nó sem deletar → memory leak.
❌ delete antes de desconectar
Salve em temp, reconecte, SÓ ENTÃO delete temp.

Stack & Heap

Toda variável em C++ vive em algum lugar da memória. Entender onde explica por que ponteiros existem, por que new precisa de delete, e como cópias, referências e ponteiros se comportam.

STACK — Pilha de Chamadas
Automática
Variáveis locais, parâmetros, endereços de retorno. Gerenciamento automático — liberada ao sair da função. Limitada (~1–8 MB). Rápida.
HEAP — Memória Dinâmica
Manual
Criada com new. Persiste além da função. Pode ser GBs. Você é responsável pelo delete. Nós de listas e árvores vivem aqui.

struct No {
    int  dado;
    No*  prox;
};

No* inserirInicio(No* head, int val) {
    No* n  = new No;
    n->dado = val;
    n->prox = head;
    return n;
}

No* inserirFim(No* head, int val) {
    No* n  = new No;
    n->dado = val;
    n->prox = nullptr;
    if (!head) return n;
    No* atual = head;
    while (atual->prox)
        atual = atual->prox;
    atual->prox = n;
    return head;
}

No* remover(No* head, int val) {
    No* atual    = head;
    No* anterior = nullptr;
    while (atual && atual->dado != val) {
        anterior = atual;
        atual    = atual->prox;
    }
    if (!atual)    return head;
    if (!anterior) head             = atual->prox;
    else           anterior->prox   = atual->prox;
    delete atual;
    return head;
}

int main() {
    No* head = nullptr;
    head = inserirInicio(head, 10);
    head = inserirFim  (head, 20);
    head = remover     (head, 10);
}

C++ — struct Lista
struct No {
    int  dado;
    No*  prox;
    No(int v) : dado(v), prox(nullptr) {}
};

// ★ struct de controle — SÓ ponteiros e metadados, sem métodos
struct Lista {
    No*  head    = nullptr;  // primeiro nó
    No*  tail    = nullptr;  // último nó — habilita inserirFim O(1)!
    int  tamanho = 0;        // quantidade de elementos
};

// ── funções livres que recebem Lista& ─────────────────

void inserirInicio(Lista& L, int val) {
    No* n   = new No(val);
    n->prox = L.head;
    L.head  = n;
    if (!L.tail) L.tail = n;  // 1º nó: head e tail apontam para o mesmo
    L.tamanho++;
}

void inserirFim(Lista& L, int val) {
    No* n = new No(val);
    if (!L.tail) {
        L.head = L.tail = n;  // lista vazia
    } else {
        L.tail->prox = n;    // antigo tail aponta para o novo
        L.tail        = n;    // tail avança — O(1)!
    }
    L.tamanho++;
}

void removerInicio(Lista& L) {
    if (!L.head) return;
    No* temp = L.head;
    L.head   = L.head->prox;
    if (!L.head) L.tail = nullptr;  // lista ficou vazia
    delete temp;
    L.tamanho--;
}

bool buscar(const Lista& L, int val) {
    for (No* a = L.head; a; a = a->prox)
        if (a->dado == val) return true;
    return false;
}

int main() {
    Lista L;                    // head=null, tail=null, tamanho=0
    inserirFim   (L, 10);       // [10]          head=tail=10
    inserirFim   (L, 20);       // [10→20]       tail=20
    inserirInicio(L, 5);        // [5→10→20]     head=5
    std::cout << L.tamanho;      // → 3  (sem percorrer!)
    removerInicio(L);            // [10→20]
}

    }

// Inverter lista — O(n), O(1) espaço extra
void inverter(No*& h) {
    No* anterior = nullptr;
    No* atual    = h;
    while (atual) {
        No* prox = atual->prox; // salva o próximo
        atual->prox = anterior;   // inverte o ponteiro
        anterior    = atual;       // avança anterior
        atual       = prox;        // avança atual
    }
    h = anterior;                  // novo head é o último
}

C++ — struct No duplo
struct NoDuplo {
    int       dado;
    NoDuplo* prox;  // aponta para o próximo nó
    NoDuplo* ant;   // aponta para o nó anterior

    NoDuplo(int v)
        : dado(v), prox(nullptr), ant(nullptr) {}
};

// ★ struct de controle — só metadados
struct ListaDupla {
    NoDuplo* head    = nullptr;
    NoDuplo* tail    = nullptr;
    int      tamanho = 0;
};


  
C++ — inserir no início
void inserirInicio(ListaDupla& L, int val) {
    NoDuplo* n = new NoDuplo(val);

    n->prox = L.head;   // novo aponta para o antigo head
    n->ant  = nullptr; // não tem nó antes de n

    if (L.head)
        L.head->ant = n;  // antigo head aponta de volta para n

    L.head = n;

    if (!L.tail)
        L.tail = n;       // 1º nó: head e tail são o mesmo

    L.tamanho++;
}


  
C++ — inserir no fim
void inserirFim(ListaDupla& L, int val) {
    NoDuplo* n = new NoDuplo(val);

    n->prox = nullptr; // não tem nó depois de n
    n->ant  = L.tail;  // n aponta de volta para o antigo tail

    if (L.tail)
        L.tail->prox = n;  // antigo tail aponta para frente para n

    L.tail = n;

    if (!L.head)
        L.head = n;          // lista estava vazia

    L.tamanho++;
}


  
C++ — remover nó (O(1) com o nó em mãos!)
// Vantagem da lista dupla: remover um nó que você JÁ TEM é O(1)
// Na lista simples, você precisaria percorrer para achar o anterior
void removerNo(ListaDupla& L, NoDuplo* alvo) {
    if (!alvo) return;

    // Reconecta o nó anterior ao próximo
    if (alvo->ant)
        alvo->ant->prox = alvo->prox;
    else
        L.head = alvo->prox;  // era o head

    // Reconecta o próximo ao anterior
    if (alvo->prox)
        alvo->prox->ant = alvo->ant;
    else
        L.tail = alvo->ant;  // era o tail

    delete alvo;
    L.tamanho--;
}

// Remover por valor — O(n) busca + O(1) remoção
void removerValor(ListaDupla& L, int val) {
    NoDuplo* atual = L.head;
    while (atual) {
        if (atual->dado == val) {
            removerNo(L, atual);
            return;
        }
        atual = atual->prox;
    }
}

// Percurso para FRENTE (head → tail)

Tópico 2 · Pilhas

  
Pilha (Stack) — LIFO

  
Último a entrar, primeiro a sair. push/pop no topo em O(1). Usada em: desfazer, chamadas recursivas, parênteses, conversão binária.

  
LIFO = Last In, First Out. Prova: "Pilha = FIFO" → FALSO.


  
Versão 1 — sem struct (ponteiro simples)

  

  

    
C++
struct No { int dado; No* prox; };

No* push(No* topo, int val) {
    No* n   = new No;
    n->dado = val;
    n->prox = topo;
    return n;              // retorna o novo topo
}

int pop(No*& topo) {
    if (!topo) return -1;
    int  val  = topo->dado;
    No*  temp = topo;
    topo      = topo->prox; // avança o topo
    delete temp;
    return val;
}

int  peek   (No* t) { return t ? t->dado : -1; }
bool isEmpty(No* t) { return t == nullptr; }

int main() {
    No* topo = nullptr;
    topo = push(topo, 10);
    topo = push(topo, 20);
    pop(topo);   // → 20
}

struct No {
    int  dado;

    No(int v) : dado(v), prox(nullptr) {}
};

// ★ struct de controle — SÓ ponteiros e metadados, sem métodos
struct Stack {
    No*  topo    = nullptr;  // aponta para o nó do topo
    int  tamanho = 0;        // quantidade de elementos
};

// ── funções livres que recebem Stack& ──────────────────

void push(Stack& s, int val) {
    No* n   = new No(val);
    n->prox = s.topo;
    s.topo  = n;
    s.tamanho++;
}

int pop(Stack& s) {
    if (!s.topo) return -1;
    int  val  = s.topo->dado;
    No*  temp = s.topo;
    s.topo    = s.topo->prox;
    delete temp;
    s.tamanho--;
    return val;
}

int  peek   (const Stack& s) { return s.topo ? s.topo->dado : -1; }
bool isEmpty(const Stack& s) { return s.topo == nullptr; }
int  size   (const Stack& s) { return s.tamanho; }

int main() {
    Stack s;                       // topo=nullptr, tamanho=0
    push(s, 10);
    push(s, 20);
    push(s, 30);
    std::cout << peek(s);         // → 30  (sem remover)
    std::cout << pop (s);         // → 30  (tamanho=2)
    std::cout << size(s);         // → 2
}

// Verificar parênteses balanceados — Exercício 6
bool balanceado(const std::string& expr) {
    Stack s;
    for (char c : expr) {
        if (c == '(')
            push(s, 1);
        else if (c == ')') {
            if (isEmpty(s)) return false;
            pop(s);

    return isEmpty(s);

Tópico 3 · Filas

  
Fila (Queue) — FIFO

  
Primeiro a entrar, primeiro a sair. enqueue no fim, dequeue no início. Precisa de 2 ponteiros: inicio (quem sai) e fim (quem entra).

  
FIFO = First In, First Out. Para enqueue O(1) no fim, mantenha um ponteiro fim. Sem ele, toda inserção seria O(n).


  
Versão 1 — sem struct

  
C++
struct No { int dado; No* prox; };

// Precisa de 2 ponteiros: ini (sai) e fim (entra)
void enqueue(No*& ini, No*& fim, int val) {
    No* n   = new No;
    n->dado = val;
    n->prox = nullptr;

    if (fim) fim->prox = n;  // antigo fim aponta para novo
    fim = n;                   // avança fim
    if (!ini) ini = n;        // fila estava vazia
}

int dequeue(No*& ini, No*& fim) {
    if (!ini) return -1;
    int  val  = ini->dado;
    No*  temp = ini;
    ini       = ini->prox;     // avança início
    if (!ini) fim = nullptr;  // fila ficou vazia
    delete temp;
    return val;
}

    No*  fim     = nullptr;  // quem entra (enqueue) — O(1) graças a esse ponteiro
    int  tamanho = 0;

// ── funções livres que recebem Queue& ──────────────────

void enqueue(Queue& q, int val) {
    No* n   = new No(val);
    if (q.fim)     q.fim->prox = n;  // antigo fim aponta para o novo
    q.fim = n;                         // fim avança
    if (!q.inicio) q.inicio = n;      // fila estava vazia
    q.tamanho++;
}

int dequeue(Queue& q) {
    if (!q.inicio) return -1;
    int  val    = q.inicio->dado;
    No*  temp   = q.inicio;
    q.inicio    = q.inicio->prox;
    if (!q.inicio) q.fim = nullptr;  // fila ficou vazia
    delete temp;
    q.tamanho--;
    return val;
}

int main() {

    enqueue(q, 10);
    enqueue(q, 20);
    enqueue(q, 30);

    std::cout << dequeue(q);          // → 10  (inicio avança para 20)

Algoritmos · Busca

  
Busca Sequencial e Binária

  
Dois jeitos de encontrar um valor num array. A diferença central: a binária é O(log n) mas exige array ordenado. Para n=1 bilhão, a sequencial faz 1 bi comparações; a binária faz 30.


  

    
Busca Sequencial
O(n)
Percorre do início ao fim. Funciona em qualquer array — ordenado ou não. Também funciona em listas encadeadas.

    
Busca Binária
O(log n)
Elimina metade dos candidatos a cada passo. Exige array ordenado com acesso por índice. Impossível em lista encadeada.

  


  
Pegadinha de prova: "Use busca binária na lista encadeada ordenada." → IMPOSSÍVEL. Busca binária precisa de arr[meio] — acesso direto por índice. Lista encadeada não tem isso.

Algoritmos · Hashing

  
Hash Tables

  
Inserção e busca em O(1) no caso médio. A ideia: uma função transforma o valor em um índice diretamente. Sem precisar percorrer.


  
Conceito de função hash

  
C++
// Função hash mais simples: resto da divisão pelo tamanho da tabela
int hash(int val, int tam) {
    return val % tam;  // resultado: sempre entre 0 e tam-1
}
// Exemplos com tam=10:
// hash(23) = 23%10 = 3  → vai para o slot 3
// hash(47) = 47%10 = 7  → vai para o slot 7
// hash(33) = 33%10 = 3  → COLISÃO com 23!


  
Colisão: dois valores diferentes mapeiam para o mesmo slot. É inevitável quando n > tam. Dois jeitos de resolver: encadeamento (lista no slot) ou sondagem linear (próximo slot livre).


  
Hash com Encadeamento (Chaining)

  
Cada slot da tabela aponta para uma lista encadeada. Colisões entram na mesma lista. Sem limite de elementos por slot.

  
C++
const int TAM = 7;
struct No {
    int  dado;
    No*  prox;
    No(int v) : dado(v), prox(nullptr) {}
};

// Tabela: cada posição é a head de uma lista
No* tabela[TAM] = {nullptr};

int  hash(int v)       { return v % TAM; }

void inserir(int val) {
    int  idx    = hash(val);
    No*  n      = new No(val);
    n->prox      = tabela[idx]; // insere no início da lista
    tabela[idx]  = n;
}

bool buscar(int val) {
    int  idx  = hash(val);
    No*  atual = tabela[idx];
    while (atual) {
        if (atual->dado == val) return true;
        atual = atual->prox;
    }
    return false;
}

int main() {
    inserir(10); // hash(10)=3 → slot 3
    inserir(17); // hash(17)=3 → slot 3 (colisão! entra na lista)
    inserir(25); // hash(25)=4 → slot 4
    buscar(17); // true: vai ao slot 3, percorre lista
}


  
Hash com Sondagem Linear (Linear Probing)

  
Sem listas — tudo num array plano. Se o slot está ocupado, avança para o próximo até achar um vazio.

  
C++
const int TAM = 7;
int  tabela [TAM];
bool ocupado[TAM] = {false};

int hash(int v) { return v % TAM; }

void inserir(int val) {
    int idx = hash(val);
    while (ocupado[idx]) {
        idx = (idx + 1) % TAM;  // sonda o próximo (circular)
    }
    tabela [idx] = val;
    ocupado[idx] = true;
}

int buscar(int val) {
    int idx = hash(val);
    while (ocupado[idx]) {
        if (tabela[idx] == val) return idx;
        idx = (idx + 1) % TAM;
    }
    return -1;  // slot vazio encontrado = não existe
}

int main() {
    inserir(10); // hash(10)=3 → slot 3 livre → ocupa
    inserir(17); // hash(17)=3 → slot 3 ocupado → tenta 4 → ocupa
    inserir(24); // hash(24)=3 → 3 ocupado → 4 ocupado → ocupa 5
}

Bubble Sort: compara pares adjacentes e troca se fora de ordem. Cada passagem "borbulha" o maior elemento para o fim. O(n²) pior/médio — O(n) melhor (já ordenado). Estável.

      
flag de parada + cocktail sort
C++
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        // Após passagem i, os i maiores já estão no fim
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp    = arr[j];
                arr[j]      = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
C++
// Otimização 1 — flag de parada antecipada
// Melhor caso vira O(n): se já ordenado, 1 passagem e para.
void bubbleSortOtimizado(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool trocou = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp    = arr[j];
                arr[j]      = arr[j + 1];
                arr[j + 1] = temp;
                trocou = true;
            }
        }
        if (!trocou) break;    // zero trocas = já ordenado, sai
    }
}

// Otimização 2 — Cocktail Shaker (bidirecional)
// Faz passagem pra frente E pra trás, reduzindo passagens totais.
void cocktailSort(int arr[], int n) {
    int  ini = 0, fim = n - 1;
    bool trocou = true;
    while (trocou) {
        trocou = false;
        for (int i = ini; i < fim; i++) {          // frente → max vai pro fim
            if (arr[i] > arr[i + 1]) {
                int t = arr[i]; arr[i] = arr[i+1]; arr[i+1] = t;
                trocou = true;
            }
        }
        fim--;
        for (int i = fim; i > ini; i--) {          // volta → min vai pro início
            if (arr[i - 1] > arr[i]) {
                int t = arr[i]; arr[i] = arr[i-1]; arr[i-1] = t;
                trocou = true;
            }
        }
        ini++;
    }
}
// Para [1,2,3,5,4]: flag-version faz 2 passes; cocktail faz 1 frente+1 volta.

Selection Sort: encontra o mínimo da parte não-ordenada e coloca na posição correta. Sempre O(n²) — mesmo se já estiver ordenado. NÃO estável (trocas trocam elementos não adjacentes). Poucas trocas no total: exatamente n-1.

C++
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;               // assume mínimo na posição i
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;           // encontrou menor
        }
        // Coloca o mínimo na posição i
        int temp     = arr[i];
        arr[i]       = arr[minIdx];
        arr[minIdx]  = temp;
    }
}
C++
// Otimização 1 — skip troca desnecessária quando já está no lugar
void selectionSortOtimizado(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        if (minIdx != i) {          // só troca se o mínimo não está no lugar
            int temp     = arr[i];
            arr[i]       = arr[minIdx];
            arr[minIdx]  = temp;
        }
    }

// Otimização 2 — bidirecional: seleciona mínimo E máximo por passagem
// Faz n/2 passagens em vez de n-1 — dobra a velocidade prática.
void selectionBidirecional(int arr[], int n) {
    int ini = 0, fim = n - 1;
    while (ini < fim) {
        int minIdx = ini, maxIdx = fim;
        for (int j = ini; j <= fim; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
            if (arr[j] > arr[maxIdx]) maxIdx = j;
        }
        if (minIdx != ini) {
            int t = arr[ini]; arr[ini] = arr[minIdx]; arr[minIdx] = t;
        }
        if (maxIdx == ini) maxIdx = minIdx;   // corrige: max estava em ini
        if (maxIdx != fim) {
            int t = arr[fim]; arr[fim] = arr[maxIdx]; arr[maxIdx] = t;
        }
        ini++; fim--;
    }
}

Insertion Sort: mantém uma parte ordenada e insere cada novo elemento na posição correta dentro dela. O(n) se já ordenado. Excelente para arrays pequenos ou quase ordenados. Usado como base do Shell Sort. Estável.

      
busca binária para a posição
C++
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int chave = arr[i];    // elemento a ser inserido
        int j     = i - 1;
        // Desloca elementos maiores que chave para a direita
        while (j >= 0 && arr[j] > chave) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = chave;   // insere na posição correta
    }
}
C++
// Otimização — busca binária para achar a posição de inserção
// Reduz comparações de O(n) → O(log n) por elemento inserido.
// ATENÇÃO: deslocamentos ainda são O(n) — complexidade total = O(n²).
void insertionSortBinario(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int chave = arr[i];
        // busca binária na parte ordenada [0..i-1]
        int lo = 0, hi = i;
        while (lo < hi) {
            int meio = lo + (hi - lo) / 2;
            if (arr[meio] <= chave) lo = meio + 1;
            else                    hi = meio;
        }
        // lo = posição de inserção — desloca [lo..i-1] uma pos para direita
        for (int j = i; j > lo; j--)
            arr[j] = arr[j - 1];
        arr[lo] = chave;
    }
}
// Comparações para n=1000:
//   Básico:  até ~500.000 (pior caso)   Binário: até ~10.000
// Deslocamentos: iguais nos dois (~250.000 médio) — gargalo real.
// Use quando comparações são caras (strings longas, objetos pesados).

Shell Sort: Insertion Sort com gaps decrescentes. Começa comparando elementos distantes (gap=n/2), depois gap=n/4, ..., gap=1. Elementos chegam perto da posição final antes do passo final. Complexidade depende da sequência de gaps — ~O(n log² n) com gaps de Knuth.

      
sequência de Knuth (1,4,13,40…)
C++
void shellSort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // Insertion sort para elementos com distância gap
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j    = i;
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j     -= gap;
            }
            arr[j] = temp;
        }
    }
}
C++
// Sequência de Knuth: 1, 4, 13, 40, 121, ...  gap(k) = 3*gap+1
// Complexidade empírica ~O(n^(4/3)) — muito melhor que a sequência n/2.
void shellSortKnuth(int arr[], int n) {
    // Calcula o maior gap de Knuth que cabe no array
    int gap = 1;
    while (gap < n / 3) gap = gap * 3 + 1;  // 1→4→13→40→121...

    while (gap >= 1) {
        // Insertion sort com passo gap
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j    = i;
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j     -= gap;
            }
            arr[j] = temp;
        }
        gap = (gap - 1) / 3;   // volta na sequência: 13→4→1
    }
}
// Comparação de gaps para n=9:
//   n/2:   gaps = 4, 2, 1   (3 rounds)
//   Knuth: gaps = 4, 1      (2 rounds) — mais eficiente
// Para n=100: Knuth usa gaps 40,13,4,1 — n/2 usa 50,25,12,6,3,1

Quick Sort: escolhe um pivô, particiona o array ao redor dele (menores à esquerda, maiores à direita), e aplica recursivamente. O(n log n) médio. O(n²) pior caso (pivô sempre o menor/maior). NÃO estável. Recursivo — usa O(log n) de memória de stack.

      
mediana de 3 + insertion para n<10
C++
int particionar(int arr[], int ini, int fim) {
    int pivo = arr[fim];  // pivô = último elemento
    int i    = ini - 1;  // índice do menor elemento
    for (int j = ini; j < fim; j++) {
        if (arr[j] <= pivo) {
            i++;
            int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
        }
    }
    int temp     = arr[i + 1];
    arr[i + 1]  = arr[fim];
    arr[fim]     = temp;
    return i + 1;           // índice final do pivô
}

void quickSort(int arr[], int ini, int fim) {
    if (ini < fim) {
        int p = particionar(arr, ini, fim);
        quickSort(arr, ini,     p - 1);  // recursão esquerda
        quickSort(arr, p + 1, fim    );  // recursão direita
    }
}
// Uso: quickSort(arr, 0, n-1);
C++
// Otimização 1 — Mediana de 3 como pivô
// Evita O(n²) em arrays já ordenados (pivô nunca será o menor/maior).
void ordenarTres(int arr[], int a, int b, int c) {
    if (arr[a] > arr[b]) { int t=arr[a]; arr[a]=arr[b]; arr[b]=t; }
    if (arr[a] > arr[c]) { int t=arr[a]; arr[a]=arr[c]; arr[c]=t; }
    if (arr[b] > arr[c]) { int t=arr[b]; arr[b]=arr[c]; arr[c]=t; }
    // Após: arr[a] ≤ arr[b] ≤ arr[c] — mediana está em b
}

int particionarMed3(int arr[], int ini, int fim) {
    int meio = ini + (fim - ini) / 2;
    ordenarTres(arr, ini, meio, fim);        // coloca mediana em meio
    int t = arr[meio]; arr[meio] = arr[fim - 1]; arr[fim - 1] = t; // pivô em fim-1
    int pivo = arr[fim - 1];
    int i    = ini;
    for (int j = ini; j < fim - 1; j++) {
        if (arr[j] <= pivo) { int tmp=arr[i]; arr[i]=arr[j]; arr[j]=tmp; i++; }
    }
    int tmp = arr[i]; arr[i] = arr[fim - 1]; arr[fim - 1] = tmp;
    return i;
}

// Otimização 2 — Insertion Sort para subarrays pequenos (n < 10)
void quickSortOtimizado(int arr[], int ini, int fim) {
    if (fim - ini < 10) {           // subarray pequeno → insertion sort
        for (int i = ini + 1; i <= fim; i++) {
            int chave = arr[i], j = i - 1;
            while (j >= ini && arr[j] > chave) { arr[j + 1] = arr[j]; j--; }
            arr[j + 1] = chave;
        }
        return;
    }
    int p = particionarMed3(arr, ini, fim);
    quickSortOtimizado(arr, ini,     p - 1);
    quickSortOtimizado(arr, p + 1, fim    );
}
// Uso: quickSortOtimizado(arr, 0, n-1);
// Mediana de 3: para array já ordenado [1,2,...,n], pivô vira
// o elemento do meio → O(n log n) em vez de O(n²).

Merge Sort: divide ao meio recursivamente (até subarrays de 1 elemento), depois mescla os subarrays já ordenados. O(n log n) GARANTIDO em todos os casos. Estável. Custo: O(n) de memória extra para os subarrays temporários.

      
bottom-up iterativo (sem recursão)
C++
void merge(int arr[], int ini, int meio, int fim) {
    int n1 = meio - ini + 1;
    int n2 = fim  - meio;
    int esq[n1], dir[n2];
    for (int i = 0; i < n1; i++) esq[i] = arr[ini  + i];
    for (int j = 0; j < n2; j++) dir[j] = arr[meio + 1 + j];
    int i = 0, j = 0, k = ini;
    while (i < n1 && j < n2) {
        if (esq[i] <= dir[j]) { arr[k] = esq[i]; i++; }
        else                   { arr[k] = dir[j]; j++; }
        k++;
    }
    while (i < n1) { arr[k] = esq[i]; i++; k++; }
    while (j < n2) { arr[k] = dir[j]; j++; k++; }
}

void mergeSort(int arr[], int ini, int fim) {
    if (ini < fim) {
        int meio = ini + (fim - ini) / 2;
        mergeSort(arr, ini,    meio);
        mergeSort(arr, meio + 1, fim);
        merge    (arr, ini,    meio, fim);
    }
}
// Uso: mergeSort(arr, 0, n-1);
C++
// Bottom-up iterativo — sem recursão, sem stack de chamadas.
// Mescla subarrays de tamanho 1, depois 2, 4, 8... até n.
// Usa a mesma função merge() do algoritmo básico.
void mergeSortIterativo(int arr[], int n) {
    for (int tam = 1; tam < n; tam *= 2) {
        for (int ini = 0; ini < n - tam; ini += 2 * tam) {
            int meio = ini + tam - 1;
            int fim  = (ini + 2 * tam - 1 < n - 1)
                       ? (ini + 2 * tam - 1) : (n - 1);
            // Otimização: pula se já ordenado
            if (arr[meio] <= arr[meio + 1]) continue;
            merge(arr, ini, meio, fim);   // mesma função merge() do básico
        }
    }
}
// Vantagens:
// 1. Sem recursão → sem risco de stack overflow para n grande
// 2. arr[meio] <= arr[meio+1] → pula merges desnecessários (quase ord.)
// 3. Melhor localidade de cache — acesso sequencial à memória
// Complexidade: mesma O(n log n) — constante menor na prática.

// tam=2: mescla [0-3],[4-7]
// tam=4: mescla [0-7]  → ordenado!

Dado o array [7, 3, 5, 1, 8, 2], mostre o estado após cada passagem completa do Bubble Sort.

  
Solução
Array inicial:  [7, 3, 5, 1, 8, 2]

Passagem 1 (i=0): compara pares, maior "borbulha" para o fim
  7>3 → troca → [3, 7, 5, 1, 8, 2]
  7>5 → troca → [3, 5, 7, 1, 8, 2]
  7>1 → troca → [3, 5, 1, 7, 8, 2]
  7<8 → ok    → [3, 5, 1, 7, 8, 2]
  8>2 → troca → [3, 5, 1, 7, 2, 8]   ← 8 está na posição final
Fim P1: [3, 5, 1, 7, 2, 8]

Passagem 2 (i=1):
  3<5 → ok, 5>1→troca, 5<7→ok, 7>2→troca → [3, 1, 5, 2, 7, 8]
  Fim P2: [3, 1, 5, 2, 7, 8]   ← 7 na posição final

Passagem 3: [1, 3, 2, 5, 7, 8]
Passagem 4: [1, 2, 3, 5, 7, 8]
Passagem 5: [1, 2, 3, 5, 7, 8]   ← nenhuma troca → encerrado

Total: 5 passagens, O(n²) = O(36) = 15 comparações no pior caso.

Q3 — Busca Binária passo a passo

  
Array ordenado: [2, 5, 8, 12, 16, 23, 38, 56, 72, 91]. Use busca binária para encontrar 23. Mostre L, R e meio em cada iteração.

Q4 — Complexidade e escolha

  
Responda: (a) Qual sort usar para ordenar 10 elementos? (b) Para 1.000.000? (c) Se os dados já chegam quase ordenados? (d) Se precisa garantir estabilidade e O(n log n)?

  
Gabarito
(a) 10 elementos: qualquer um. Insertion Sort — simples, O(n²)
    não importa para n pequeno. Overhead de Quick/Merge não compensa.

(b) 1.000.000 elementos: Quick Sort na prática (mais rápido na
    maioria dos casos por cache performance). Alternativa: Merge Sort
    se precisar de garantia O(n log n) e estabilidade.

(c) Quase ordenado: Insertion Sort! O(n) no melhor caso — percorre
    o array uma vez quase sem trocas. Shell Sort também bom.

(d) Estável + O(n log n) garantido: Merge Sort.

Q6 — Hash com colisão

  
Tabela de tamanho 5. Insira os valores [10, 23, 5, 18, 30, 12] usando: (a) encadeamento; (b) sondagem linear.

  
Solução
hash(v) = v % 5

(a) Encadeamento:
  hash(10)=0  hash(23)=3  hash(5)=0 (colide com 10)
  hash(18)=3 (colide com 23)  hash(30)=0 (colide)  hash(12)=2

  Slot 0: [30→5→10→NULL]   Slot 1: NULL
  Slot 2: [12→NULL]        Slot 3: [18→23→NULL]   Slot 4: NULL

(b) Sondagem Linear:
  10 → hash=0 → slot 0 livre  → [10, _, _, _, _]
  23 → hash=3 → slot 3 livre  → [10, _, _, 23, _]
   5 → hash=0 → slot 0 ocupado → tenta 1 → livre → [10, 5, _, 23, _]

  12 → hash=2 → 2 ocup → 3 ocup → 4 ocup → volta: 0 ocup → 1 ocup → TABELA CHEIA (erro)

Q03Busca Binária

    

      
Modifique a busca binária para informar quantas comparações foram necessárias para localizar o elemento.

      
💡 Macete: Declare int& comparacoes como parâmetro e incremente dentro do while, antes do if. Pior caso: ⌈log₂(n)⌉ comparações. Para n=10 são no máximo 4 comparações.

      

        
C++
int buscaBinariaContando(int arr[], int n, int alvo, int& comparacoes) {
    int ini = 0, fim = n - 1;
    comparacoes = 0;
    while (ini <= fim) {
        comparacoes++;              // incrementa ANTES do if
        int meio = ini + (fim - ini) / 2;
        if      (arr[meio] == alvo) return meio;
        else if (arr[meio] <  alvo) ini = meio + 1;
        else                        fim = meio - 1;
    }
    return -1;
}
// {2,4,6,8,10,12,13,14,16,18}, busca 13 → idx=6, comparacoes=4

}

💡 Macete: Faça DOIS buscas binárias: uma busca a primeira ocorrência (quando achar, continue buscando à esquerda com fim=meio-1) e outra busca a última (continue à direita com ini=meio+1). Resultado = última - primeira + 1.

int primeiraOcorrencia(int arr[], int n, int alvo) {
    int ini = 0, fim = n - 1, res = -1;
    while (ini <= fim) {
        int meio = ini + (fim - ini) / 2;
        if      (arr[meio] == alvo) { res = meio; fim = meio - 1; } // continua esquerda
        else if (arr[meio] <  alvo)   ini = meio + 1;
        else                          fim = meio - 1;
    }
    return res;
}

int ultimaOcorrencia(int arr[], int n, int alvo) {
    int ini = 0, fim = n - 1, res = -1;
    while (ini <= fim) {
        int meio = ini + (fim - ini) / 2;
        if      (arr[meio] == alvo) { res = meio; ini = meio + 1; } // continua direita
        else if (arr[meio] <  alvo)   ini = meio + 1;
        else                          fim = meio - 1;
    }
    return res;
}

int contarOcorrencias(int arr[], int n, int alvo) {
    int p = primeiraOcorrencia(arr, n, alvo);
    if (p == -1) return 0;
    return ultimaOcorrencia(arr, n, alvo) - p + 1;
}
// Ex: [1,2,2,2,3,4], alvo=2 → primeira=1, última=3, count=3

      

    

  


  

    
Q18Desafio — Bubble Sort

    

      
Modifique o Bubble Sort para ordenar em ordem decrescente. Também: versão com flag que para quando o array já estiver ordenado.

      
💡 Macete decrescente: Mude arr[j] > arr[j+1] para arr[j] < arr[j+1]. É a única mudança necessária. Macete flag: Use uma variável booleana que começa true antes do inner loop. Se alguma troca ocorrer, seta false. Se ficar true ao fim do inner loop, nenhuma troca aconteceu → sai.

      

        
C++
// Decrescente: só muda o sinal de comparação
void bubbleSortDesc(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] < arr[j + 1]) {    // < em vez de >
                int t = arr[j]; arr[j] = arr[j+1]; arr[j+1] = t;
            }
        }
    }
}

// Com flag (para se já ordenado — O(n) melhor caso):
void bubbleSortFlag(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool ordenado = true;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int t = arr[j]; arr[j] = arr[j+1]; arr[j+1] = t;
                ordenado = false;      // houve troca
            }
        }
        if (ordenado) break;       // nenhuma troca → já ordenado
    }
}

      

    

  


  

    
Q19Desafio — Selection Sort

    

      
Modifique o Selection Sort para colocar os maiores elementos primeiro (ordem decrescente).

      
💡 Macete: Troque "procura o mínimo" por "procura o máximo". Mude arr[j] < arr[minIdx] para arr[j] > arr[maxIdx] e renomeie a variável. O resto do algoritmo é idêntico.

      

        
C++
void selectionSortDesc(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int maxIdx = i;               // busca o MÁXIMO agora
        for (int j = i + 1; j < n; j++) {
            if (arr[j] > arr[maxIdx])  // > em vez de <
                maxIdx = j;
        }
        int t = arr[i]; arr[i] = arr[maxIdx]; arr[maxIdx] = t;
    }
}

      

    

  


  

    
Q20Desafio — Insertion Sort

    

      
Modifique o Insertion Sort para ordenar apenas os números pares, mantendo os ímpares em suas posições originais.
Exemplo: {9,8,3,4,7,6,1,2,5,0} → pares {8,4,6,2,0} nas pos {1,3,5,7,9} → ordenados {0,2,4,6,8} → resultado: {9,0,3,2,7,4,1,6,5,8}

      
💡 Macete (3 passos): ① Extraia os pares com suas posições originais para arrays auxiliares. ② Rode insertion sort APENAS no array de pares. ③ Recoloque os pares ordenados de volta nas posições originais. Os ímpares nunca são tocados.

      

        
C++
void insertionSortSoPares(int arr[], int n) {
    int pares[100], posicoes[100], np = 0;

    // Passo 1: coleta pares com suas posições
    for (int i = 0; i < n; i++) {
        if (arr[i] % 2 == 0) {
            pares   [np] = arr[i];
            posicoes[np] = i;
            np++;
        }
    }

    // Passo 2: insertion sort só nos pares
    for (int i = 1; i < np; i++) {
        int chave = pares[i], j = i - 1;
        while (j >= 0 && pares[j] > chave) {
            pares[j + 1] = pares[j]; j--;
        }
        pares[j + 1] = chave;
    }

    // Passo 3: recoloca pares ordenados nas posições originais
    for (int i = 0; i < np; i++)
        arr[posicoes[i]] = pares[i];
}
// {9,8,3,4,7,6,1,2,5,0} → {9,0,3,2,7,4,1,6,5,8}

Q25Hash — sondagem linear

void inserir(int val, int tab[], bool ocup[], int tam) {
    int idx = val % tam;
    while (ocup[idx]) idx = (idx + 1) % tam;  // sonda circularmente
    tab [idx] = val;
    ocup[idx] = true;
}

    

  


  

    
Q26Hash — contar colisões

    

      
Modifique a inserção por sondagem linear para contar colisões a cada inserção.

      
💡 Macete: Cada vez que o while do while (slot ocupado) executa mais uma iteração, isso é uma colisão. Incremente o contador dentro do while. Se o slot original estiver livre (0 iterações do while), houve 0 colisões nessa inserção.

      

        
C++
int inserirContandoColisoes(int tab[], bool ocup[], int tam, int val) {
    int idx      = val % tam;
    int colisoes = 0;
    while (ocup[idx]) {
        idx = (idx + 1) % tam;
        colisoes++;                  // cada probe é uma colisão
    }
    tab [idx] = val;
    ocup[idx] = true;
    return colisoes;
}
